# 模型版本与类别解析

当前网页和对外displayPrediction使用strong-background-2026-10-15-v1：固定24维编码、训练内标准化、L2=0.01逻辑回归，保留实验/未校准标识。work/strong-models与work/strong-predictions.json保存其参数及独立首次判断。激活前旧作品只作当前试算，不补造首次。

background-inference.mjs中的v4继续提供属性编码和原模型研究档案。object-types.mjs按已核实label解析具体类别，原始name保留；例如具体名称不会让熊猫或地球仪类别漏读。未知名称不猜物种，不能因为牛油果含牛字而匹配牛。有其他明确花/叶色的植物不算纯绿，棕色枝干仍可伴随绿叶。未确认或跨帧关系不触发叠放。

原v4的L2=1概率在currentModelView保留，旧v3在background-inference-v3.mjs独立保留；不能将它们的首次判断或回测成绩标为强增权实验。语义规则、特征编码、研究选择及展示模型分别有版本，改动时不改写旧协议和观察。

feature-weight-study-2026-10-15-v1预先冻结四配置，在开发段比较，后段仅评价开发选定配置。默认强增权显示是固定研究选择，不表示它在该比较中胜出。新增标签分别重训当前配置，首次判断不变，历史导入不计前瞻。

模型仅训练24个已定义属性，未重新训练视觉网络，也未对所有新名称建立系数。数据不足、未知数量、无对照或场景不适用时保留缺失/不输出。
