# 特征权重与相似案例

当前默认只显示固定标准化L2=0.01强增权实验。它是用户选择的研究配置，未校准，不能因概率更极端就称更好。原v4、v3及所有首次判断独立保留；当前字段使用displayPrediction。

独立研究feature-weight-study-2026-10-15-v1预先冻结原始L2=1和标准化L2=1/0.1/0.01。按目标日去重，前70%日期为开发段，每折至少24个可得标签；后30%只评价开发段按Brier选出的配置。历史及特征定义已被查看，后段仍不是全新盲测。固定显示强增权不挪用开发选定配置的后段成绩。

均值、标准差、支持门槛和完全同现分组仅来自当折训练数据。二元出现与未确认各至少5日，连续值至少20个已知值；稀少或恒定特征不增强。完全同现的属性共享系数，避免重复投票；权重由数据拟合，不强制迎合语义先验。

概率误差使用Brier与对数损失，越低越好。主卡45%—55%附近显示接近均衡/信号弱；不保证每条画面都拉开。逐条属性影响使用显示中的强增权模型，将某属性置为训练均值后重算，属于敏感度，不是因果，各项不能简单相加。

原冻结研究中的开发段遮去属性指标随研究结果保留，不能当成新的强增权独立验证。相似案例固定取属性距离最近8个不同目标日，排除自己及同目标日代表；旧图重看可以使用之后标签，案例涨跌比例不是预测概率。

首次完整研究位于work/feature-weight-study-first-result.json，不覆盖、不移动原切分。新增标签对研究选定配置和固定显示配置分别重训；强增权的新观察首次位于work/strong-predictions.json，旧作品不补称首次。所有运行档案和截图由.gitignore排除。

方法：[概率校准与损失](https://scikit-learn.org/stable/modules/calibration.html)、[时间顺序验证](https://scikit-learn.org/stable/modules/cross_validation.html#time-series-split)。
